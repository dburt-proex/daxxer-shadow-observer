# Bounded release acceptance

This release completes the requested local Shadow Operator v0.1 ledger and
the ON/OFF observer extension. Completion means the following implemented,
locally verifiable behaviors, not future learning-platform capabilities:

- Validated episode/record/intake/VIL schemas and untrusted-source prompts.
- Append-only JSONL streams, deterministic SHA-256 chains, provenance,
  immutable evidence and outcome/correction revisions.
- Deterministic training eligibility that excludes incomplete/unverified,
  unreviewed and held-out episodes.
- Explicitly scoped read-only sources, bounded text capture, baseline/backfill,
  secret heuristics, link exclusion, rescan deduplication and source rotation.
- Verified ON/STATUS/OFF, OS-released writer/control/scan locks, graceful stop,
  stale/error reporting and no startup installation.
- Automatic conservative episode capture, optional loopback Ollama review,
  no action tools, no cloud fallback, no automatic human attestation.
- Tests, GitHub CI definition, operating instructions and recovery procedures.
- One genuine current-work observation with unknown publication/outcome state;
  validated datasets and generated experience summary.

External publication/deployment is separately approval-gated. Training models,
promotion/earned authority, arbitrary application integrations, full desktop
surveillance and DeepSeek Harness installation are outside this release.

The user requested completion of this repository. That authorizes the local
architecture, schema and file changes needed for this scope. It does not grant
the observer authority to modify any existing DAXXER project.
